# 🗺️ Карта проекта HIZSQUAD

Документация для того, чтобы не сойти с ума после перерыва в месяц.
Здесь написано, какой файл за что отвечает и где искать нужный код.

## 📂 Корневые файлы (Главные страницы)
*   **`index.html`** — Главная страница сайта (экран "Привет, мы", кнопки контактов, общая инфа).
*   **`portfolio.html`** — Страница со всей сеткой твоих проектов.
*   **`vite.config.js`** — Мозг сборщика Vite. Сюда ОБЯЗАТЕЛЬНО нужно прописывать пути для всех новых страниц в блок `rollupOptions.input`, иначе они не соберутся в продакшен.

---

## 📂 Папка `blocks/` (HTML-компоненты / Кусочки страниц)
*Файлы отсюда склеиваются (инжектятся) в главные страницы, чтобы не писать один и тот же код по сто раз.*
*   **`header.html`** — Шапка сайта (логотип, навигация: Главная, Услуги, Портфолио). Подключена везде.
*   **`footer.html`** — Подвал сайта (копирайты, ссылки).
*   **`card-project.html`** — Шаблон ОДНОЙ карточки для портфолио. Сама сетка лежит в `portfolio.html`, но код карточки управляется отсюда.

---

## 📂 Папка `pages/` (Второстепенные страницы)
*   **`services.html`** — Страница услуг (сейчас пустая/в разработке).

### 📂 Подпапка `pages/projects/` (Страницы конкретных кейсов)
*Здесь живут полноценные отдельные страницы для каждого твоего проекта (вместо старых поп-апов).*
    *   **`site-hs.html`** — Детальный разбор, описание и стек технологий твоего текущего сайта.
    *   **`game-trailer.html`** — Страница с пред-трейлером (видео из DaVinci) и его описанием.

---

## 📂 Папка `css/` (Стили и внешний вид)
*   **`base.css`** — Базовые глобальные настройки сайта (сброс отступов браузера, цвета фона всего сайта, шрифты).
*   **`hero.css`** (или блок в `style.css`) — Стили главного экрана (анимации, размытия, фиолетовые неоновые цвета).
*   **`feedback.css`** — Стили для кнопок связи (Telegram / Contact), надзаголовка "Трейлер в разработке" и элементов инпута.
*   **`portfolio.css`** — Стили адаптивной сетки карточек (`.portfolio-grid`) и эффектов наведения (hover) на них.
