## 🛠 Шпаргалка по командам терминала (HizSquad)

### 💻 Локальная разработка (На компьютере)
* `npm run dev` — Запустить локальный сервер. Сайт будет доступен по адресу `http://localhost:5173`.
* `npm run build` — Обычная тестовая сборка проекта в папку `docs` (проверить на ошибки).

---

### 🚀 Сборка проекта для GitHub Pages (Управление техработами)
* `npm run build:prod` — Собрать **РАБОЧИЙ** сайт (выключить техработы).
* `npm run build:maintenance` — Собрать сайт в **РЕЖИМЕ ТЕХРАБОТ** (включить заглушку).

---

### 📦 Отправка обновлений на GitHub (Деплой за 3 шага)
После того как выполнил нужную команду сборки выше, пиши эти команды по очереди:

1. `git add .` — Добавить все измененные файлы в очередь.
2. `git commit -m "feat: описание того что ты сделал"` — Закоммитить изменения.
3. `git push origin main` — Пульнуть код на GitHub (через минуту сайт обновится в сети).
